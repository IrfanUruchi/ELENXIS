# Architecture — high-level research overview

The project separates scientific evidence acquisition, structured context and assumptions, symbolic comparison and numerical assessment. Its language-level research components include Haskell, SWI-Prolog, GNU Fortran and Python.

The key decision is **whether a proposed comparison has enough trustworthy context to be performed at all**. A documentary mismatch, statistical uncertainty overlap, methodological difference and logical incompatibility are not interchangeable findings.

This overview does not describe specific private algorithms, trusted-reference formats, implementation interfaces, production deployment arrangements or confidential experimental datasets. The private framework is not distributed by this repository.
